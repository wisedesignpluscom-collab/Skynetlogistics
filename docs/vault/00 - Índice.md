# Índice — Skynet Logistics

Vault de notas de diseño del proyecto. Complementa a [[../../CLAUDE.md|CLAUDE.md]], que sigue siendo
la fuente de verdad para el estado general de fases y las reglas de trabajo. Este vault existe para
que las notas de diseño detalladas de fases nuevas vivan en archivos separados y enlazados, en vez de
seguir apendizando un único CLAUDE.md cada vez más largo.

## Convención

- Una nota por fase o sub-fase nueva (ej. `Config-C - Workflows.md`), con el mismo nivel de detalle
  que antes se agregaba directo a CLAUDE.md.
- CLAUDE.md mantiene solo el **resumen de una línea + estado** de cada fase, con un link a la nota
  de detalle aquí cuando exista.
- Las notas se enlazan entre sí con `[[wikilinks]]` cuando una fase depende de o extiende a otra.
- No se migra contenido histórico de CLAUDE.md a menos que se pida explícitamente — este vault aplica
  hacia adelante.
